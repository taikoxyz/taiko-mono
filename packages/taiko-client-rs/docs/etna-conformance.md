# Etna client conformance record

This record maps the client work to the Etna specification at `178d7a7a6` (#22425, the L2
staking alignment on top of #22422, #22419 and #22412). Paths below are relative to
`packages/taiko-client-rs`. It covers generation-zero networks, including nonzero Unzen starts,
and governance recovery. The pinned execution node is Alethia
`7174fd0064c69fa75ce784b8ec13702fffa5d429`, which makes the block-start staking call;
consensus remains unmodified CometBFT v0.40.0. The lander's
dummy proof restricts this implementation to development chains. Until the protocol pin moves
to a #22286 revision with `EtnaStaking`, the tests below use values written by hand from the
specification's appendices and vector files where the shared vectors have no family yet.

The Unzen driver handoff and nonzero-S lander/import paths are described in [the handoff
runbook](unzen-etna-handoff.md). Their switch checks (SYNC-9-5a, PROOF-6.2-46a, PARAM-11-12a
and the client side of START-10-5a/5d) are mapped below with their behavioral tests; the driver
drain behind `etna-handoff` has none yet. Public EL snapshot download, export,
hosting and distribution are outside this update. Local verification of independently acquired
complete EL state is included. This record does not certify production resource budgets, public
archive availability, real proof guests or a deployment.

The protocol rule index includes retired IDs and non-binding limitations. The map uses current binding IDs. Applicable host behavior is distinguished from L1 state-transition ownership, implementation delegated to the pinned EL, operator policy, and real proof/launch measurements. The conformance suite (`crates/abci/tests/etna_conformance.rs`) runs three historical formal-model regression families and two client-owned families transcribed from the specification (`miss_bitmap`, `candidate`); its fixture README records provenance and known divergences. The pinned byte fixtures have a separate reproducibility check in `shared_vectors_match_the_pinned_protocol_copy`.
