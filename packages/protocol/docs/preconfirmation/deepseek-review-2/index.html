What is genuinely good (verified positives)

  • Liveness engineering: degradation ladder + mechanical T_exp + re-queue/refund forced queue survive a permanent proving outage (checker-verified; the four-guarantee liveness split is honest).
  • The two-sided anarchy cutoff closes the empty-front-running horn without breaking cadence; W_a = 0 recovers v10 byte-for-byte.
  • The v14 bridge fix (terminal destination-side FAILED mark) restores FAILED⊥DONE exclusion and matches the deployed Bridge/SignalService semantics — the v12 not-DONE snapshot was indeed unsound (verified against Bridge.sol).
  • I8 precommitted payees elegantly kill reward-front-running across proofs, pokes, fills, and recoveries.
  • Forced-inclusion time-travel is provably impossible (F_delay ≥ E + margin ⇒ execution timestamp > submission wall time) — a non-obvious, correct consequence of r9-C1.
  • L1-builder timestamp manipulation is neutralized (slot-indexed decisions and anchors; no inclusion-time derivation inputs).
  • Honesty culture: the doc's worst properties (watchtower dependence, spike residual, monopoly acceptance, band lags) are largely stated — the review's job was mostly to quantify and to find the things not yet stated.

Confidence & method transparency

  • Independently verified (two separate agent passes + my own re-checks): the model-checker results (reproduced bit-for-bit, 5 run configurations), every line citation in every report, all arithmetic, the deployed-contract semantics (Bridge/SignalService/Inbox/PreconfWhitelist), and the ten headline findings (all verified TRUE by an independent refutation pass).
  • Simulated (illustrative, assumptions stated): auction outcomes under 0/1/2/3/5 bidders, incumbency renewal, anarchy race economics, equivocation breakeven, timestamp windows. Parameter values (seat value ≈ 0.20 ETH/epoch, reserve 0.01, noise 18%) are placeholders — the structure of the results (rent dissipation, reserve monopoly, p<1 undersizing, time-travel impossibility) does not depend on them.
