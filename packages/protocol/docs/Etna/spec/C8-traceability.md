## 1. Purpose and method

**[assumed: method]** D44 item 3 ([WORK.md](../WORK.md) item 3) asks that "Each rule names its owner, inputs, failure behaviour and test vector" (J's W10 census reads this as naming "an owner, its inputs, its failure behaviour, and a test vector in C8 or in the section's vector list"), and that C8 define every error "with reference vectors that an implementer can test against". This page supplies the two things the census found missing:

1. **A rule-to-vector trace per owner section (§2).** For each rule it records the owner, the inputs the rule text names, the failure behaviour the rule text states, the vectors that exercise it, and the elements missing. The initial mapping was made by reading each vector's scenario against each rule's text. W18 adds explicit owning-rule references in C1 and C4; the other sections retain the initial reviewer mapping. Some vectors' own text names a rule: C1's V06 (C1-R08 step 4), V12 (C1-R06) and V13 and V16 (C1-R05); C3's T36 (R10) and T19 (C7-R11); C5's G01 (C5-R13), G02 (C5-R12) and H01 (C5-R07); C7-T15 (C7-R04); and S1-V01 (S1-R13), S1-V03 (S1-R14), S1-V05 (S1-R11), S1-V09 and S1-V17 (S1-R07), S1-V12 (S1-R13, S1-R14) and S1-V14 (S1-R16, S1-R18). These are examples, not a complete list: C1's V11 (C1-R08) and V15 (C3-R08), C2's E06 (C2-R15, C2-R21) and E11 (C2-R04's V3 clause), C7-T10, C7-T14 and C7-T16 (C3-R05(b), C3-R07, S1-R15 to S1-R18) and S4-V01 (S4-R01, S4-R04) name rules too (C3-T19's citation of a C7 rule is noted in §2.6). Every cell in a Vectors column is therefore a claim to be verified by the owner, not a property of the owning section: it says "this tracer read vector X as exercising rule Y", and an owner who reads the scenario differently corrects the cell, not the rule. Vector ids keep each section's own convention (bare `T01` in C3, `S1-V01` in S1, `C7-T06` in C7, `E01` in C2, `G01` in C5, `V01` in C1), quoted as the section writes them.
2. **A gap summary (§3)** per section and per element, counted from §2's tables.
3. **An error and revert vector family for C8 (§4),** one vector per error name C8 declares, each derived from the rule text that raises the error, or, for C8-E23 and C8-E28, from C8-R07's sketch pairing a name with a condition the owner states; for C8-E21 and C8-E22, C8-R07 names the pair for `withdrawFiRefund`'s two requirements without saying which name is which, so the per-name split is this page's reading by name **[assumed]**, awaiting C8 and C3; C8-E18 is a non-reverting boundary (§4.4). An error whose trigger no text in the tree defines is listed as an open gap, never given an invented condition.

**[assumed: id convention]** C3, C4 and S1 write their vectors bare (`T01`, `V01`); C7 and C8 prefix them (`C7-T06`, `C8-V08`). This page writes every vector with its section prefix (`C3-T13` is C3's `T13`), so a prefixed id that does not appear verbatim in its section is that section's bare id, not a dangling reference (J's review of #22230).

**[assumed: owner convention]** The owning section is the default owner of each of its rules; a rule that places content in another section names the owning rule and section explicitly. D71 records this convention. Section ownership does not imply that missing definitions or fixtures are supplied.

**[assumed: counting conventions]** An element counts as present when the rule text states it; the conventions of each section's tracer (owner taken from the section header, failure stated by citation, degraded outcomes) are recorded at the head of each subsection in §2 and are not harmonised here, so a stricter reading of one convention moves a count, as the subsection notes say. A vector that the owning section marks **open** (an obligation without bytes) is still cited, because item 3 asks for a named vector; §3 records which sections' vectors are all open.

**[open: verification]** W18 submits B's C1/C4 mapping confirmations and component vectors for A/J review; no self-approval or executed-fixture claim follows. Other owner confirmations and every remaining fixture/definition gap stay open. This page shows coverage and named gaps, not that item 3 passes; J's §4 item 3 ("do not treat item 3 as passing on the strength of a reviewer's reading") applies to this page too.
