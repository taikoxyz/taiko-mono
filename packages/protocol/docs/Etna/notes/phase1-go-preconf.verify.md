## Missed facts

- `OnUnsafeL2Request` performs its up-to-1 s deterministic jitter wait **while holding `s.mutex`** (`server.go:505-506` lock; `593-607` timer select), so every incoming block request stalls the HTTP builder and all other gossip handlers for up to 1 s. — `driver/preconf_blocks/server.go:505,593-607`
- When the EE reports syncing, `ImportMissingAncientsFromCache` returns `nil` (success) rather than an error, so `TryImportingPayload` skips the cache-and-quit branch and tries to insert a block whose parent is unknown. — `driver/preconf_blocks/server.go:797-800`, `1407-1430`
- The request and EOS-request topics are **unauthenticated**: `PublishL2Request`/`PublishL2EndOfSequencingRequest` have no signer (`// TODO: add signer, sign request`), and their validators only rate-limit (per-peer 200 tokens/min, per-hash 45 s window, per-epoch >3 ignore). Any peer can make every operator node perform block lookups and publish responses. — `OPNODE/op-node/p2p/gossip.go:881-882`, `511-557`, `560-613`
- `verifyBlockResponseSignature`'s IGNORE branch (`len(addrs)==0`) is unreachable: `P2PSequencerAddresses()` always returns two entries, so a node without lookahead REJECTs responses just as it rejects blocks. — `OPNODE/op-node/p2p/gossip.go:842-844`; `driver/preconf_blocks/server.go:1058-1061`
- The `preconfBlocks` validator does not require the embedded `envelope.Signature`; a block gossiped without it is accepted and stored with an all-zero `L1Origin.Signature`, which later makes it unservable on the response topic (`sig == [65]byte{}` skip). Wire signature and embedded signature are therefore independently optional/required. — `OPNODE/op-node/p2p/gossip.go:373-408`; `driver/preconf_blocks/server.go:302-305`, `578-589`; `common.go:660-663,776`
- `IsSyncing()` edge: if `taikoAuth_lastL1OriginByBatchID(NextProposalId-1)` is not found, `HighestOriginBlockID` is set to MaxUint64, so with `eth_syncing` non-nil the node reports "syncing" until that mapping exists; `CurrentBlockID` is 0 when there is no head L1 origin. HTTP builds then get 400 and all gossip is cached. — `pkg/rpc/methods.go:480-498`, `504-516`
- `removeOperator`/`removeOperatorByAddress` take effect **immediately** (`IMPORTANT: The operator is removed immediately`) while `addOperator` is delayed `OPERATOR_CHANGE_DELAY = 2` epochs; removal changes `operatorCount`, hence `operatorMapping[randomNumber % _operatorCount]`, so the current epoch's operator can change mid-epoch. The driver picks this up on the next L1 block (lookahead refresh is per new L1 block). — `packages/protocol/contracts/layer1/preconf/impl/PreconfWhitelist.sol:93-95,99-110,292`; `driver/driver.go:459-497`
- For `slotInEpoch < 2` the lookahead (and therefore the accepted gossip signer set `[Curr, Next]`) is not refreshed; the previous epoch's operator pair stays authorized for the first two slots of each epoch. The `lookahead == nil ||` guard is dead code since the lookahead is never nil. — `driver/driver.go:497`; `driver/preconf_blocks/server.go:161`
- All slot/epoch gates are computed from the **host wall clock** (`CurrentSlot() = (now - genesisTime)/SecondsPerSlot`), not from observed L1 blocks: HTTP window check, EOS epoch keys on builder and receivers, `/status` `canShutdown`.
