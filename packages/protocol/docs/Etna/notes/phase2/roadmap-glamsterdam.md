## 2. Timing

### Slot timing — VERIFIED
- `SECONDS_PER_SLOT: 12` / `SLOT_DURATION_MS: 12000` on Sepolia, Hoodi and mainnet; unchanged by Gloas. (eth-clients configs, fetched 2026-09-30.)
- Gloas intra-slot deadlines (Sepolia config): `ATTESTATION_DUE_BPS_GLOAS: 2500` (3 s), `AGGREGATE_DUE_BPS_GLOAS: 5000` (6 s), `PAYLOAD_DUE_BPS: 5000` (6 s), `PAYLOAD_ATTESTATION_DUE_BPS: 7500` (9 s), `MIN_BUILDER_WITHDRAWABILITY_DELAY: 64` epochs, `MAX_PAYLOAD_SIZE: 10485760`.
- EIP-7732 rationale: next proposer gets 6 s (`SECONDS_PER_SLOT*2//INTERVALS_PER_SLOT`) and other validators 9 s to validate the payload; a tx included by the builder in slot N "is not widely validated until the proposer of slot N+1 releases their beacon block on top of block N". Slots can be *Full*, *Skipped* or *Empty* (beacon block on-chain, execution payload not).
- Slot-time reduction: EIP-7782 DFI; EIP-8198 Quick Slots B-tier for Hegotá (EF tier post 2026-09-07).

## 3. What this means for an L2 landing batches on L1 (synthesis, derived from VERIFIED specs above)

1. **Inclusion latency/finality of batch txs**: with ePBS the execution payload containing a batch is revealed at ~6 s into slot N and only becomes canonical-in-practice once slot N+1's beacon block builds on it; "empty" slots (builder withholds) are a new failure mode. Preconf/based-sequencing logic that assumes "block N is executed by attesters of slot N" must be revisited.
2. **DA cost**: calldata floor 64 gas/byte (EIP-7976) + access-list surcharge (EIP-7981) make calldata DA materially more expensive; blob DA is unchanged (21 max, EIP-7918 reserve price) — no new blob capacity in this fork.
3. **L1 contract gas**: EIP-8038/8037/2780/7778 raise SSTORE/new-slot/new-account costs sharply (STORAGE_WRITE 10,000; new slot +97,920 state gas) and remove refund relief from block accounting; contracts that write fresh storage per batch/proposal should be re-benchmarked. The intrinsic cost of a value-less call drops to 15,000.
4. **Header/proof formats**: new EL header fields (`block_access_list_hash`, `slotNumber`), new Engine API versions, and CL SSZ merkleization changes (EIP-7688) affect any L1-header or beacon-root proof verification.
5. **EVM equivalence**: SLOTNUM, SWAPN/DUPN/EXCHANGE, SELFDESTRUCT-burn removal, 64 KiB code size, ETH-transfer logs must be mirrored by a type-1 L2 EVM to remain equivalent.
6. **Capacity**: 200M gas limit schedule on Sepolia at Gloas (mainnet pending) plus block-level access lists → more L1 gas per block for batch/prove txs, still capped at 16.78M per tx (EIP-7825).
