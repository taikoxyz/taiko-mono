L1 dependency set

Nothing scheduled for Glamsterdam or Hegotá is a hard dependency. Etna launches on today's Fusaka mainnet; the forks change its environment, not its primitives. Source: 02-l1-roadmap-survey.md (facts verified against the EIP repository and client configs on 2026-09-30).

Optional (improves cost, latency or safety)

  • EIP-8141 Frame Transactions (Hegotá SFI, Draft): zero-cost landing races and the two-shape gate. See Frame transactions. Degrades to plain type-3 transactions with a deadline.
  • EIP-4788 beacon roots + EIP-7688 stable gindices: only if a role is ever tied to L1 validator facts. Etna's registry is self-contained and does not need them.
  • EIP-7805 FOCIL (Hegotá SFI): an L1-level inclusion floor for small transactions (slashing evidence, registrations, forced-inclusion requests). It does not cover blob-carrying transactions, so it never protects a landing.
  • EIP-8272 recent roots, EIP-8250 keyed nonces (Hegotá CFI): mempool-level invalidation of race losers; concurrent submissions.
  • EIP-7843 SLOTNUM: the only slot-agnostic slot primitive, unused by design.

Tolerate (environment changes the design must survive)

  • ePBS (EIP-7732): payload revealed at 50 % of the slot, canonical in practice at slot N+1, Empty slots. Etna consequence: L1 inclusion of a landing is confirmed one slot later than today; the EIP-4788 buffer has gaps at Empty slots; never read a beacon root by slot timestamp.
  • Gas repricing: EIP-8037 charges 97,920 state gas per new storage slot. Etna consequence: registration is priced to cover its new slots; the landing hot path writes only overwritten ring-buffer slots.
  • Header and proof formats: block access lists, slotNumber, empty logsBloom. Etna consequence: none, no L1 header field is parsed on L2 except the block hash and state root carried by the anchor.
  • Blob market: reserve price 8192 × base fee per blob, sparse blobpool. Etna consequence: the lander reward must cover the reserve price at every slot time.
  • Slot time: EIP-7782 (6 s, Glamsterdam DFI), EIP-8198 Quick Slots (Hegotá PFI). Etna consequence: see the table below.
  • EIP-8151 account-code-restricted ecrecover: slashing and attestation keys are code-less EOAs or BLS keys. assumed the EIP ships in its A-tier form.

Claims

  1. proven Glamsterdam SFI list contains no EIP Etna calls; ePBS and BALs change timing and header layout only (EIP-7773 master, 2026-09-30).
  2. proven Hegotá SFI = FOCIL + Frame Transactions; ethereum.org gives "Q2 2027, date not confirmed"; mainnet slot time is 12 s in every published config.
  3. proven EIP-7825 caps one transaction at 16,777,216 gas; a landing near the cap does not fit a 10 M-gas block.
  4. assumed Blob retention stays about 18 days in wall clock under shorter slots (EIP-8198 says windows scale to preserve duration; EIP-7782 is silent).
  5. open Whether sub-4-s L1 deadlines are feasible at all is an open L1 question (EIP-8198 phase 2). Etna does not need them.
