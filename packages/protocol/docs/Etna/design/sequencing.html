Sequencing rights

Time is cut into 60-second terms. Within a term, each takeover opens a new view (view 0 is the primary holder, view v the v-th backup). The holder of a term is a pure function of the registry as it stood 20 minutes before the term and of a randomness seed fixed one hour ahead. Every node computes it identically and in advance; the inbox verifies the same function at landing. No slot, epoch, beacon root, lookahead or blockhash is read anywhere in this block.

What today does and why it fails

One PreconfWhitelist operator per 384-second epoch, chosen by beaconRoot % operatorCount from an EIP-4788 root probed in 12-second steps; roster edited by the owner or ejecters; an offline operator loses the whole epoch with no replacement and no penalty; clients read the roster at "latest" so nodes disagree near boundaries (00 §3.1, §9.2, §9.4). This fails R1 (TH19), R5 (TH15), R6 (TH9, TH10), and the locality property P7 (TH12).

1. Time

TERM = 60 s, termOf(τ) = (τ − T0) / TERM, T0 = the term-grid origin. The DAO's upgrade transaction calls initEtna(lastFinalizedBlockNumber) without T0; a second upgrade-class call armEtna(T0) with T0 ≥ now + MIGRATION_LEAD sets the grid once the DAO has read the domain count and, off-chain, the owner structure (round 4, R4-C5). CYCLE_TERMS = 60, so one seed per hour. Every quantity is a second count, an L1 block timestamp or a count.

Invariant I1 (sortition is a pure function of state at S(t)). For every term inside ROLE_HORIZON, the holders and committee the inbox computes at landing time equal what nodes computed at termStart(t), whatever registry mutations became effective in between. Every rule in §2, §3 and §5 is derived from it.

2. Registry: seats and future-dated writes

Storage lives in the upgraded Inbox proxy after its 43-slot gap; logic in a linked library so the landing path reads it without an external call and the existing TAIKO bond ledger is reused (R2: no new address). proven the syncer address stays the Inbox proxy.

  • Seat: one unit of bond B_SEAT and one storage slot Seat{owner, activeFrom, activeUntil} in an append-only array of at most 65,535 (a 16-bit index; filling it costs 1.31 billion TAIKO, above the supply). An owner holds at most CAP = 8 seats. A slot is written fresh once (97,920 state gas under EIP-8037, paid by the entrant) and only overwritten afterwards.
  • Operator record: {seatCount, strikes, lastStrikeAt, exitAt, two suspension intervals}; the landing reserve is a ledger quantity (landing page §5).
  • Rule D (future-dated effect): a registry write at L1 time τ changes eligibility only for instants T ≥ τ + DELAY, with DELAY_REG = 7200 s for entry and exit, the only inputs that change E_t or a rank, and DELAY_S = 1320 s for class A or B suspensions, which change no rank (round 5, R5S-2), both ≥ LOOKBACK + 2·TERM. Term t evaluates eligibility at the single instant termStart(t), and eligible(i, T) is computable from current storage for any T inside ROLE_HORIZON: every seat keeps activeFrom and activeUntil, every owner its suspension intervals (a flag read after the draw, never an input to the rank domain), and a recycled hole has activeUntil + RECYCLE_GRACE ≤ now, so it was ineligible at every still-landable term either way. Term t reads the version of the domain tree effective at termStart(t) (§5), so writes effective later change nothing and no proofs are needed.
  • Eligibility-input rule (round 4, R4-C2; restated in round 5, R5S-2): every input that changes E_t or a rank is DELAY_REG-dated; a suspension changes neither. Entry and exit are the only inputs to the rank domain, and both are owner-triggered writes dated τ + DELAY_REG. Suspensions of every kind set or clear a per-owner flag that is read only after a seat is drawn: a suspended seat drawn as a holder is a void view (skipped without timeout, as void views already are, §5), and drawn as a committee slot it is an empty slot (m shrinks by one, Q(m) scales, no re-draw shifts later slots, §8). Which objects the flag covers and why the rule holds for each: class A and B suspensions are DELAY_S-dated and can be self-inflicted, since the offender may be its own challenger (slashing page §1) and S6 accepts a header the owner produced privately, but a self-inflicted suspension moves no rank, so it costs a seat or the ledger and changes no draw of any term; reserve lapses, the hard floor (crossed by a MISS applied at a landing whose timing anyone, the owner included, can choose) and reactivate() are DELAY_REG-dated and act through the same flag. No owner write changes a committee after the seed is fixed, so RND3 holds for every input.
  • register(count) requires bond ≥ 1.05 × (seatCount + count)·B_SEAT + (seatCount + count) × LAND_RESERVE (LAND_RESERVE = 9,200 TAIKO per seat, landing page §5), a registered code-less sequencer key and a BLS attester key with proof of possession over (pubkey, owner, chainId), unique across the registry (see Slashing; the owner itself may be a contract), and no pending exit. A fresh owner has a 5 % buffer (1,000 TAIKO per seat = 20 timeouts) before a liveness debit touches seat stake, and the hard floor at 50 % is the only liveness-driven suspension; the reserve is ring-fenced from liveness debits and is never withdrawable while any seat is active or pending (round 4, R4H-3). Indices are contract-assigned: FREE recycled holes first (expired plus RECYCLE_GRACE), then appends at the scheduled length, so a same-block append by an incumbent never reverts an entrant's transaction (round 2). The array is dense, so its length always equals the number of seats ever claimed; requestExit(seats) takes any count of the owner's seats, each seat one domain write (round 5, R5-C4); it is accepted for a seat only once τ + DELAY_REG ≥ activeFrom + MIN_TENURE with MIN_TENURE = 604,800 s (7 days) and sets activeUntil = τ + DELAY_REG, so a seat is eligible, drawn and bled for at least a week and every domain write takes effect at τ + DELAY_REG, monotone in transaction order (round 5 fix pass, §5); finalizeExit after activeUntil + EVIDENCE_WINDOW (7 days) releases seat stake and reserve together; while seats exist, withdrawal is limited to the excess over 1.05 × seatCount·B_SEAT + seatCount × LAND_RESERVE.
  • inDomain(i, T) := activeFrom ≤ T < activeUntil is what sortition reads: E_t counts these seats and ranks run over them. suspended(owner, T) is read after the draw, from the two suspension intervals, which hold class A and B suspensions (DELAY_S-dated), reserve lapses (DELAY_REG-dated, at least SUSPEND(3) long, landing page §5) and hard-floor suspensions (DELAY_REG-dated, open-ended until reactivate() closes the interval at τ' + DELAY_REG). eligible(i, T) := inDomain(i, T) ∧ ¬suspended(owner, T) is what a drawn seat must satisfy to hold a view or fill a committee slot (round 5, R5S-2).

3. Snapshot rule

S(t) = the highest L1 block with timestamp ≤ termStart(t) − LOOKBACK, LOOKBACK = 1200 s. A node replays registry events and the mix log up to S(t); no archive state is needed. Agreement with the contract: any write in a block after S(t) has τ + DELAY > termStart(t) + TERM, so both views evaluate term t without it; any write whose effect falls after termStart(t) creates a later version of the domain tree, and term t reads the version effective at termStart(t) (§5), so the inbox evaluates term t over the same domain the node did (invariant I1). proven (claim 2). Under a total L1 halt the schedule stays defined.

4. Randomness

Compared: an EIP-4788 root (slot-keyed probe, fork-dependent gindices, Empty-slot gaps, 4.6-h window at 2-s slots: rejected); an EIP-2935 header proof of a timestamp-defined block's prevrandao (fork-dependent header RLP, a per-cycle transaction: kept as an upgrade path); round-robin with no randomness (predictable forever, terms sellable: rejected). Chosen: a prevrandao accumulator.

  • RND1. land, every registry mutation and the public no-op poke() execute, at most once per L1 block, seedAcc = keccak(seedAcc ‖ block.prevrandao). Each emits an event, so nodes replay the mix log in block order.
  • RND2. seed(c) = keccak(DOMAIN ‖ chainId ‖ seedAcc_at(T_seed(c)) ‖ c) with T_seed(c) = cycleStart(c) − LOOKBACK. The first mixing call at or after T_seed(c) fixes it on-chain; nodes compute the same value from the log without waiting.
  • RND3 (freshness). fresh(c) iff a mix occurred after freshFrom(c) = cycleStart(c) − 3660 s, the last instant at which a registry write can affect cycle c. When fresh, no registrant could know the seed when it last had a chance to change roster inputs. proven (claim 5). When not fresh (no landing and no poke for 41 minutes, itself a total-censorship event), the residual lever is a few bits of seat placement.

L1-proposer bias: the proposers of the last m blocks before T_seed(c) hold two bits each (reveal or skip; include or exclude a mixing transaction), so m colluding proposers choose among at most 4m seeds for one 60-term cycle. Same bound as every RANDAO consumer, including today's 4788 path. assumed RANDAO model.

5. Selection: weighted random by seats, hash walk, views

Compared: term auctions (an L1 transaction per term per bidder, dead exactly when L1 is congested, capital buys everything, still needs a random fallback: rejected); round-robin (rejected as above); weighted random with a cap (chosen).

  • Rank-based sortition over a versioned tree (round 4, R4H-1; rebuilt in the round-5 fix pass). idx(t, k) = keccak(seed(c) ‖ 0x01 ‖ t ‖ k) mod E_t is a rank among the seats in the domain at termStart(t) (registered and inside [activeFrom, activeUntil); suspension is read after the draw, round 5, R5S-2), in seat-id order, where E_t is their count; the seat at rank r is the r-th such seat id. Seat identity is the append-only array index and never moves. The contract keeps the domain as a persistent (versioned) segment tree over seat ids: every domain write (an entry or an exit, nothing else; suspensions and lapses are flags, round 5, R5S-2) creates a new version by path copying, about 16 fresh nodes per seat (≈ 1.6 M gas of state under EIP-8037, paid by the writer), tagged with its effective time E = τ + DELAY_REG. Effective times are monotone in transaction order, because every domain write uses the same delay and requestExit is accepted only once τ + DELAY_REG ≥ activeFrom + MIN_TENURE, so the version log is sorted by E with no reordering. Term t reads the latest version with E ≤ termStart(t) (a binary search of the log). A version is immutable once written, and every version with E ≤ termStart(t) exists from termStart(t) − DELAY_REG on, so the inbox's answer for term t at any later time equals the node's answer at termStart(t) (invariant I1; claims 1 and 2). No mutation ring, correction set, lazy application or per-slot cap exists: a walk reads one version, and its cost does not depend on how many writes happened since the term started (§8 gives the gas; round 5 fix pass: round 4's Fenwick tree corrected by a mutation ring made the stalest pin cost grow with the number of writes since the term began, and no per-slot cap both kept it inside one transaction and left entrants undelayable). Sortition is over registered seats only: an owner who registers and exits seats never dilutes anyone (round 3, H5: with the walk over the whole array, 3,000 phantom indices held for nine days made most terms open-empty). P(no holder) = 0 whenever E_t ≥ 1.
  • Churn is priced, not capped. MIN_TENURE = 7 days means every seat that enters is drawn and bled for at least a week at B_SEAT of stake, and every domain write pays for its own tree version (about 1.6 M gas of state per seat). No rule limits how many writes may take effect per minute, so no incumbent can delay or crowd out an entrant's registration (round 5 fix pass: the per-slot cap round 5 had added let an incumbent delay an entrant by 60 s per 2 seats registered ahead of it). A class-A-slashed owner's seats can be exited by anyone with exitSlashed(owner, seats), effective τ + DELAY_REG and subject to the same tenure rule, so slashed seats do not stay in the domain as permanent void entries (round 5 fix pass).
  • Walk. For k = 0..63: skip ranks already visited; append the seat's owner to the holder list H if not yet present; stop at 5 distinct owners or when every domain seat is visited. The walk does not read suspension, so it is a pure function of the domain at termStart(t).
  • Views. holder(t, v) = H[v] for v < |H|; beyond that, view v is the owner of the seat at rank idx(t, v). A view whose owner is suspended at termStart(t) (a class A or B suspension, a reserve lapse or the hard floor) is void and skipped without any timeout, exactly as a repeated rank beyond |H| is (round 5, R5S-2). At most V_MAX = 4 takeovers happen in one term; after that the term idles to its end.
  • Share. An owner with w of A eligible seats is primary with probability w/A; CAP bounds one address to 8/A; Sybil cost is linear in seats; exclusive control needs every eligible seat and cannot be held against an honest entrant whose append is a plain L1 transaction live two hours later. proven (claims 6, 7).
  • No cooldown, no weight halving. A consecutive-term cooldown is defeated by two addresses and couples term t to t−1; fractional weights cannot be expressed by a seat walk. Both are replaced by binary suspension with strikes.

6. Open terms and dead mode

A term is open-empty if the walk finds no eligible seat, and the chain is in dead mode if termOf(now) − lastLandedTerm > DEAD_TERMS = 75. In either, any address with bond ≥ B_SEAT may sequence with the sentinel view 255 and the first landing on L1 wins. (Forced batches use the sentinel view 254 and are the forced-inclusion page's concern.) A third open regime, no-committee mode, applies to any term whose committee walk finds fewer than K_MIN_CERT = 8 eligible non-holder seats: the holder is still chosen by sortition, no certificates exist, landings are accepted with an empty certificate, and users get the sequenced level only (the launch condition on the Anchor page is meant to keep launch out of this mode). Unlike dead mode, the landing right of a no-committee term is reserved to its sortition holder until the term's economic deadline (termEnd + LAND_WINDOW); only after that may any bonded address land from lastLanded (round 2, S9: an open race from the start let any bonded outsider void the holder's minute for gas). Every sentinel-view chain opens with the object keccak("ETNA_DEAD" ‖ lastLanded.blockHash ‖ t), which the Anchor accepts as a fresh opening object after any landing (Anchor A5) and which enters every equivocation key. Between 8 and 32 seats the committee is smaller and the quorum scales with it (§8). Dead mode needs no certificate, no attester and no registration delay: a chain whose whole registry and committee vanished is recovered by one honest bonded party within about 75 minutes plus proving. It is the one rule that is not a pure function of S(t): it depends on the node's current view of lastLandedTerm, only ever adds authorized sequencers, and the landing contract arbitrates. proven bounded disagreement, confined to recovery.

7. Absent holder: takeover, penalty, suspension

  • Holder of view v is replaced by the next non-void view when a view change VC(t, v, lock) exists: ≥ Q(m) of the term's m committee signatures (22 of 32 at full size), each signed only by an attester that, for TIMEOUT = 5 s by its clock, saw no new certificate of (t, v) while holding no block of the view that it attested and that is still uncertified (round 4, R4H-4; bounded in round 5, R5H-1 and restated on the attester's own attestations in the fix pass; the certificate page is normative for the timeout trigger). A leader whose blocks the honest attesters attested and a minority keeps uncertified is never timed out, so an abstaining minority can only blank a term, never take the view; a holder that gets nothing attested is timed out at 5 s outside the collusion and split cases of certificate page §1(d). The rightful holder is the highest view with a VC closing every non-void view below it; a holder's first block carries the VC, so a partitioned node verifies signatures instead of trusting its clock. The new holder starts at the last certified block; uncertified blocks are unextendable and unlandable, so withheld blocks are worthless.
  • Absence penalty, applied by the inbox when a landed batch carries a timeout view change (no separate accusation transaction exists): MISS_PENALTY = 50 TAIKO, 100 % burned so a backup allied with attesters gains nothing from a false view change; one debit per (term, view). A timeout never changes eligibility: it adds no strike and triggers no floor check, because silence is judged by local clocks and is not slashable (red-team round 1, F3); since round 4 the bleed applies only to a leader silent to the whole committee, so an honest online leader is never bled and a false view change needs Q colluders (outside T11). MISS is debited from the 5 % buffer above the floor, then from seat stake down to the 50 % hard floor, never from the landing reserve (round 4, R4-C4). Squatting is deterred by the bleed, which reaches every non-serving holder that does not collude, because a holder that gets nothing attested is timed out (certificate page §1; round 5, R5H-1); the colluding and committee-splitting cases of certificate page §1(d) keep a view to term end without it: a seat that never serves loses 50 TAIKO per draw and reaches the 50 % hard floor after 200 draws from the floor (220 from a full buffer; about five days at 40 seats), at which point it is suspended until topped up.
  • Committee redraw (certificate page §5, round 4, R4-C1): attesters that attested a block of (t, v) but saw no certificate for TIMEOUT seconds may vote to redraw the committee of (t, v) for the same leader, at most REDRAW_MAX = 2 times per view; the redraw takes the first K seats of keccak(seed ‖ 0x03 ‖ t ‖ n ‖ m) with the exclusions of §8. It changes no holder and applies no penalty; it only raises the number of abstainers needed to blank a term from 11 to 16 of 32.
  • Evidence slash (from Slashing): a safety offence takes the whole ledger; a structural one takes one seat and adds one strike (round 5, R5S-6).
  • Suspension at three strikes, where strikes come only from structural offences (class B on the slashing page: a signed object naming an invalid certificate or view change, or a REPLACE or RESUME lock vote whose signed L1 reference did not satisfy the replacement predicate): [τ + DELAY_S, τ + DELAY_S + SUSPEND(3)·2^min(n−3, 4)) with SUSPEND(3) = 129,600 s (36 h) so that roles stay exact through the 34-hour landing horizon, stored as two intervals; a suspension changes no E_t and no rank: the owner's seats stay in the domain and are void views or empty committee slots when drawn (round 5, R5S-2); the dropped interval is provably dead for every still-landable term. A reserve lapse (landing page §5) is stored in the same two intervals as [τ + DELAY_REG, τ + DELAY_REG + SUSPEND(3)) at minimum, so every stored interval is at least 36 h long and the two-interval invariant holds for every input (round 4, R4-C2). proven (claim 3).
  • Bond floor: after a class A or class B evidence debit, a bond below seatCount·B_SEAT means open-ended suspension until top-up plus reactivate(), whose eligibility effect is DELAY_REG-dated (τ + 7,200 s, the parameters and interfaces pages; round 4 fix, R4-C2 class). MISS, the only class-C debit, never triggers that check; the hard floor it can reach (ledger below 0.5 × seatCount·B_SEAT after about 220 bleeds of one seat from a full buffer) suspends open-endedly with a DELAY_REG-dated effect, and the return is the same top-up plus reactivate() at τ' + DELAY_REG; reward-type debits (ramp, blob reward, per-landing reward, attester share) are paid from the landing reserve only and never touch seat stake or the buffer; only the 50 % hard floor suspends for liveness bleed (Slashing §6), so a chain-wide proving outage never suspends the honest set.

8. Committee hook

committeeOf(t): the first K = 32 distinct domain seats of a second walk keccak(seed ‖ 0x02 ‖ t ‖ m) over at most MAX_TRIES_COMMITTEE = 512 tries, skipping every seat of the term's primary holder (view 0, excluded by owner: the committee must not certify its own blocks) and the specific seats of the backups (excluded by seat only, so a backup's other seats may attest; a backup that takes over is then certified by a committee it may sit in, which the collusion count already includes since it counts the leader). Owner repeats among the rest are allowed, so the committee is stake-weighted. A drawn seat whose owner is suspended at termStart(t) is an empty slot: it stays in the walk's output, m shrinks by one, Q(m) scales, and no re-draw shifts the later slots (round 5, R5S-2). Which objects this covers and why invariant I1 and the grinding bound hold for each: class A and B suspensions (DELAY_S-dated, possibly self-inflicted), reserve lapses and hard-floor suspensions (DELAY_REG-dated) all act through this flag; none moves a rank or E_t, so an owner that suspends itself after the seed is fixed removes only its own slots and cannot change which other seats sit in any committee or which owner holds any view; the ranks depend on DELAY_REG-dated entry and exit only. Computed on-chain, never taken from calldata (round 4 fix, invariant I1): committeeOf(t) is walked by the inbox in the domain-tree version effective at termStart(t) (§5), each try one rank lookup of log₂(registry size) node reads, by recordAssignment(t) or by the first landing that settles t, and the result is pinned as committeeRoot[t] = keccak of the 32 attester key hashes; a CommitteeProof supplied with a certificate or evidence is checked against that root, so nobody can pin a committee of its own choosing. Worst case 576 rank lookups (64 holder tries and 512 committee tries), each a descent in one version: about 1 M gas at a 128-seat registry (at most 255 distinct nodes, each read cold once), about 4 M at 4,096 seats and about 9 M at the 65,535-seat maximum (about 4,000 distinct cold nodes) assumed, independent of how many writes happened since the term started, so every pin fits one transaction under the 16.8 M EIP-7825 cap at every registry size (round 5, R5H-2, and the fix pass). The gas is paid once per term by whoever pins it, and the pinner is paid PIN_REWARD (0 at term end, rising to PIN_MAX = 400 TAIKO over LAND_WINDOW) from the term holder's reserve (skipped when the pinner is the holder); PIN_MAX pays a pin at the launch registry (about 0.8 M gas) in full up to about 75 gwei, and a pin is never urgent, because the version it reads never changes. A landing of a term inside ROLE_HORIZON whose committee is not yet pinned computes it in the same transaction (its gas is added to that landing), so landers pin ahead with recordAssignment(t), which is callable only once termStart(t) has passed (§10). The committee size is therefore at most min(32, E_t − seats(primary) − |H| + 1), less any empty slot, and a committee is drawn without replacement from that pool, so cartel share of a committee follows the hypergeometric law, not the binomial (round 3, H7). Full committees need E_t ≥ K + CAP + V_MAX = 44 eligible seats; at exactly 44 the committee is the whole remaining pool and any two owners holding 12 seats sit with a blocking minority whenever at most one of their seats was drawn as a backup (about 40 % of terms). The published launch condition (Anchor page §5; read by the DAO before calling armEtna(T0), not enforced by the contract, round 3, C4) is therefore ≥ 8 distinct owners and ≥ 72 seats in the domain, at which an 8-seat cartel of single seats blanks 0 % of terms (simulated; table on the slashing page §5). It is a heuristic over a Sybil-able, revocable count that no rule enforces or protects (a seat can be exited seven days after it was registered, MIN_TENURE, and the count includes seats whose owner may be suspended), chosen so that a small cartel blanks few terms at launch; if it fails, launch may begin in no-committee mode (round 4, R4-C5). MIN_OWNERS is liveness sizing, not an anti-monopoly bound (round 2, F1: excluding every holder by owner emptied the committee of the honest set whenever the honest set was five large owners). If fewer than 32 are found, the committee is the m seats found: the quorum is a function of the actual size, Q(m) = ⌊2m/3⌋ + 1, and a term with m < K_MIN_CERT = 8 is in no-committee mode (certificate-free landings, sequenced level only). The certificate page owns the certificate formats, the timeout and the security statement per m (the number of provably slashable double-signers behind a locked block is 2Q(m) − m: 12 at m = 32, 6 at m = 16, 4 at m = 8).

10. Interface sketch

/// @custom:security-contact security@taiko.xyz
/// L1: storage in the Inbox proxy after __gap; logic in linked library LibSequencerRegistry.
interface ISequencerRegistry {
    struct Seat     { address owner; uint32 activeFrom; uint32 activeUntil; }
    struct Operator { uint16 seatCount; uint8 strikes; uint32 lastStrikeAt; uint32 exitAt;
                      uint32 s1; uint32 e1; uint32 s2; uint32 e2; }
    struct Holders  { address[5] owners; uint16[5] seats; uint8 count; uint8 mode; } // 0 SORTITION, 1 OPEN_EMPTY, 2 DEAD, 3 NO_COMMITTEE (as on the interfaces page)

    // permissionless mutations; every eligibility effect is future-dated (Rule D)
    function register(uint16 _count) external returns (uint16[] memory seats_);   // indices contract-assigned
    function requestExit(uint16[] calldata _seats) external;    // any count of the caller's seats; one domain write per seat, accepted once τ + DELAY_REG ≥ activeFrom + MIN_TENURE (round 5 fix pass)
    function finalizeExit(uint16[] calldata _seats) external;
    function reactivate() external;
    function poke() external;                       // mixes prevrandao; emits Poked

    // "who may sequence at time t" (nodes)
    function termOf(uint48 _time) external pure returns (uint32 term_);
    function sequencerAt(uint48 _time, uint8 _view)
        external view returns (uint32 term_, address holder_, uint16 seat_, uint8 mode_);

Every call that computes a right (land, poke, recordAssignment, evidence) reads the domain-tree version effective at the term's start, found by binary search of the version log; versions are written in transaction order with monotone effective times (§5), so nothing is applied lazily and no call order matters (round 5 fix pass). The interfaces page is normative for the struct and evidence types.

The block's term, view and seat travel in the anchor calldata (see Anchor) and extraData keeps its 7-byte engine shape pctg(1) | termId(4) | view(1) | kind(1); the P2P envelope carries assignmentDigest, so a node whose own digest differs knows its L1 view is stale before it rejects the block. Roles stay computable on-chain for ROLE_HORIZON = 34 h after a term's start (seat recycling and suspension intervals are sized for it), which is the landing horizon: every landing and every poke() also pins the assignment digest and committee root of each term it settles, and anyone may pin a term with recordAssignment(t) once termStart(t) has passed (a pin before term start is refused; round 4 fix, I1). The committee root is the inbox's own walk over the domain-tree version effective at termStart(t), never a calldata value (§8). A term older than the horizon whose digest was never pinned is unlandable and therefore replaceable; this is the one time-based void in the design, stated on the limitations page. 12. Attacks defended and not defended

  • TH3 absent holder: defended. Replacement within TIMEOUT per dark view, where dark means that the committee saw no new certificate for 5 s and attested nothing of the view that is still uncertified, whatever headers were gossiped (certificate page §1, round 5, R5H-1); void views free; 50 TAIKO burned per event, nothing else.
  • TH9 monopolization: bounded and priced below one third, not defended above it (round 4, R4-C1). Share X of primary terms against H honest seats costs H·X/(1−X) seats (with H = 64: 50 % = 64 seats = 1.28 M TAIKO, 90 % = 576); this is the price of primary share only. Productive revenue is another matter: a cartel holding a blocking minority of a committee and of both its redraws (16 of 32) can withhold certification of an honest primary's term (a blank term: no takeover, no penalty, nothing of it lands), and blank terms shift revenue without shifting primaries. Simulated (slashing page §5 table): below about 25 % of seats a cartel gains nothing; at the T11 boundary (one third) it gains about 5 points of revenue against a dispersed honest set and about 11 against the eight 8-seat honest owners of the launch condition (round 5, R5-C2); above it the gain is superlinear and the design does not defend it (limitation L2). A timeout is signed solely on leader silence (certificate page §5, round 4, R4H-4), so an abstaining minority never takes a view or bleeds the leader.
  • TH10 squatting: defended by bleed. Only a block the honest attesters attested stops the timeout (round 5, R5H-1, R5-C1), so a holder that gossips headers without serving gets nothing attested and is timed out at 5 s like a dark one, unless a blocking minority of the committee colludes with it or it splits the committee (certificate page §1(d)): a seat that never serves loses 50 TAIKO per draw (about 1,800 TAIKO per day at 40 seats) and is suspended at the 50 % hard floor after 200 draws; it earns no attester reward meanwhile.
  • Grinding: defended when fresh, bounded otherwise. Requires 41 minutes of total L1 censorship of Etna transactions, after which the lever is a few bits. No suspension, self-inflicted or not, changes a rank, so no owner write changes a committee after the seed is fixed (round 5, R5S-2).
  • Seed bias by L1 proposers: bounded. ≤ 2 bits per proposer of the last m blocks; best of 4m seeds moves a term count by a few terms per cycle.
  • TH12 reorg: defended to finality.
  • TH8 false view changes: bounded, not prevented. A timeout is signed only by an attester that, for TIMEOUT seconds, saw no new certificate of (t, v) and holds no block of the view that it attested and that is still uncertified (round 4, R4H-4, bounded in round 5, R5H-1; the honest attesters attested a held leader's two real blocks, so they never time out a producing leader whatever a minority does); an abstaining minority can only withhold certification for that term (a blank term, no takeover, no penalty), and the committee redraw makes that cost 16 of 32 seats rather than 11. A false view change needs Q colluding signatures, outside T11. The remaining loss from an honest timeout (a partitioned or slow leader) is one view and 50 TAIKO burned, never eligibility (no strike); the committee walk of §8 keeps the honest set's seats in the committee even when the honest set is a few large owners (round 2, F1). There is no accusation object anywhere in the block.
  • TH6 targeted preparation: not defended. The assignment is public 20-80 minutes ahead. Mitigation is replacement within TIMEOUT; secret leader election is out of scope.
  • TH18 EIP-8151: defended by code-less EOAs at registration and a two-branch evidence rule (if the key acquired code, slash for that L1 fact; else verify the signature pair).

13. Failure analysis

  • All seat holders offline. Every term dies after at most 4 timeouts (V_MAX); each certified absence bleeds 50 TAIKO, so within days dark owners hit the hard floor and terms become open-empty. If the committee is dark too, terms end unlanded until DEAD_TERMS pass; then dead mode lets one honest bonded party sequence and land without certificates. Liveness within about 75 minutes plus proving, no DAO action.
  • All seat holders malicious. They cannot finalize invalid state, skip due forced inclusions, block an honest registration, or hide equivocation. Withholding becomes absence. An honest entrant gets its proportional share two hours later.
  • Committee dead (fewer than Q(m) live seats). No view changes, so takeovers stop and an absent primary loses its term for everyone; the term is closed by a FALLBACK view change that any later committee, gated by L1 time, may sign (certificate page §5, round 5, R5S-5: L1 accepts it only from termEnd(t) + END_GRACE + VC_FALLBACK × (t' − t), only while no live VC of committee(t) is recorded, and lands it only with a certificate at its lock), and the next primary's first block carries it. A committee that is small because the registry is small has a proportionally small quorum (§8), so a small honest registry certifies normally with weaker collusion bounds that are published per term.
  • Provers dead. Nothing is voided or debited until the landing page's replacement predicate opens (35 to 65 minutes after the last landing); then a replacement or forced batch may land from lastLanded and the unlanded backlog is reorganised with no penalty to anyone (round 4, R4H-5; limitation L6); mixing continues via poke().
  • Partition. A holder cut off for TIMEOUT is replaced; on reconnection it verifies the view change and stops. A node cut off from L1 keeps a correct schedule for 22 minutes and labels later confirmations "L1-stale".

15. Robustness

6/4/2-s slots: nothing counts slots; LOOKBACK spans 200/300/600 blocks while finality shrinks, so the margin grows; isHolder is ≈ 7k gas typical, ≤ 290k worst case, fitting a 10 M-gas block. Without Frame Transactions: zero dependency; no registry call is a race. ePBS Empty slots and 4788 gaps: 4788 is never read; the next block's prevrandao reflects every intervening reveal; one-slot-later confirmation is absorbed by the 1320-s minimum delay. EIP-8037: fresh slots only at registration.

16. Claims

  1. proven Locality (I1): holders, committee, eligibility, seed and domain count of every term inside ROLE_HORIZON are pure functions of L1 data at S(t), and the inbox recovers them from the domain-tree version effective at termStart(t), which is immutable once written; dead mode is the stated exception and only adds rights.
  2. proven Node snapshot equals landing-time computation: Rule D makes every write made after S(t) effective after termStart(t) + TERM, so the domain-tree version effective at termStart(t) is fixed by S(t); a later write only appends a version with a later effective time and copies, never changes, the nodes it shares, so the inbox reads at landing the version a node read at S(t) (round 5 fix pass).
  3. proven The two-interval suspension store never drops a live interval.
  4. proven Reorg safety under T1 at every slot time.
  5. proven No grinding of any kind when the seed is fresh: every input that changes E_t or a rank (entry, exit) is DELAY_REG-dated, and no suspension, reserve lapse or self-submitted slash changes a rank, so no owner write changes a committee after the seed is fixed (round 4, R4-C2; round 5, R5S-2).
  6. proven Share bound w/A on primary terms, cap 8/A, exclusive control needs every seat; the revenue share differs from the primary share above about 25 % of seats (slashing page §5, not proven linear).
  7. assumed Exclusive control cannot be sustained (TAIKO liquid; a registration includable on L1 within hours).
  8. proven for dead mode, assumed for the certificate path: liveness with one honest funded party.
  9. proven Objective punishment: every debit needs a view change, a signature pair, or an L1 fact.
  10. assumed Seed bias bound (RANDAO model).
  11. assumed Freshness holds in normal operation (one landing or poke per 41 minutes).
  12. assumed Gas figures (a committee pin about 1 M at 128 seats and about 9 M at the seat maximum; a domain write about 1.6 M gas of state per seat under EIP-8037); need a prototype measurement.
  13. open B_SEAT and MISS_PENALTY absolute values pending a fee and MEV revenue model (gap G8).
  14. assumed TIMEOUT = 5 s has negligible honest false positives (gossip delay ≪ 1 s).
  15. open EIP-8151 contingency depends on that EIP's inclusion status.

17. Alternatives rejected

  • Round-robin (predictable forever, O(A) position scans); term auctions (per-term L1 transactions, capital buys everything); Merkle sum tree with sortition proofs and maintenance drains (nine proofs per landing); a 448-seat bitmap with non-evictable incumbents; EIP-2935 header proofs for the seed (kept as upgrade); EIP-4788 seeds; consecutive-term cooldown; weight halving; 24-h exclusion on the first miss; 10 % liveness slash (too costly under TC griefing); BLS registration keys (150-200k gas per verification; revisit if EIP-8151 is scheduled); linear-scan fallback; swap-and-pop seat arrays (index reuse changes computed terms); a positional eligible list maintained by swap-and-pop, removed in round 4 (R4H-1: it kept no history, so any mutation effective inside a term's landing window changed the term's computed holders and stalled landing for 35 to 65 minutes); mandatory per-term pins before every mutation (a pin per term per call, gas paid by whoever mutates); suspended seats removed from the rank domain, the rule of rounds 1 to 4 that round 5 replaced (R5S-2: a self-submitted class-B slash was a DELAY_S-dated owner write into E_t after the seed was fixed); a Fenwick tree over "eligible now" corrected at landing by a mutation ring of future-dated writes, rounds 4 and 5 (the correction made the stalest pin's gas grow with the number of writes; a per-slot cap either failed to bound it inside one transaction or let an incumbent delay entrants; replaced by the versioned tree in the round-5 fix pass); TERM = 120 s.

18. Open questions

  1. Should the absence bleed scale with the owner's seat count so multi-seat squatters reach the floor as fast as single-seat ones?
  2. "MISS_PENALTY burned, never paid to the taking-over holder" is adopted; paying it would create an incentive for false view changes.
  3. Is the P8 super-linear-cost requirement satisfied by linear seat cost plus CAP plus per-incident slashing, or is an identity-bearing primitive wanted?
  4. Is a VRF-based secret leader election worth about 100k gas per landing to close the 20-80-minute TH6 window?
  5. Should the DAO be able to raise CAP by constant upgrade only (MAX_SEATS is fixed by the index type)?
  6. Adopted from the slashing page: the owner is separate from the signing keys (one extra slot per operator); the owner may be a contract.
