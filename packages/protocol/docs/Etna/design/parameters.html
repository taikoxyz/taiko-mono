Parameters

One table for every constant the design names. Units are seconds, gwei of TAIKO, wei, gas, L1 block counts (only where L1 itself is block-denominated) or counts. R5 audit: no parameter in any block is denominated in L1 slots or epochs; the three block-denominated values are the L1-given blockhash and EIP-2935 windows and the attester-policy anchor lag, whose wall-time range is stated. Amounts in TAIKO are formulas instantiated with assumed inputs (a term's revenue ≈ 0.01 ETH, 1 TAIKO ≈ 1.5·10−4 ETH) and are open until measured.

1. Dependency chain

DELAY_S  = LOOKBACK + 2·TERM                              = 1,320 s   (registry writes never touch a term already evaluated)
DELAY_REG > CYCLE + LOOKBACK − TERM                       = 7,200 s   (no grinding when the seed is fresh)
ROLE_HORIZON = COMMITTEE_RING·TERM                        = 122,880 s (34 h: the landing horizon; roles pinned for every settled term)
SUSPEND(3) ≥ ROLE_HORIZON + DELAY_S                       = 129,600 s (the two-interval store never drops a live interval)
RECYCLE_GRACE ≥ ROLE_HORIZON + DELAY_S                    = 129,600 s (a recycled seat never changes a decided term)
DEAD_TERMS·TERM > LAND_WINDOW_MAX + ABANDON_GRACE         = 4,500 s   (a slow but live chain never enters dead mode; 75 terms)
RETAIN_SECONDS ≥ LAND_WINDOW_MAX + ABANDON_GRACE + slack  = 7,200 s   (attesters serve data until any landing is possible)
ROTATION_OVERLAP ≥ LAND_WINDOW_MAX + ABANDON_GRACE + prove= 7,200 s   (an image rotation never orphans an in-window proof)
ANCHOR_MAX_AGE + TERM + LAND_WINDOW_MAX + ABANDON_GRACE   = 5,760 s   < EIP-2935 window at 2-s slots (16,382 s)
FI_EXPIRY + ANCHOR_MAX_AGE + LAND_WINDOW_MAX + ABANDON_GRACE ≈ 7 d 95 min < blob retention (≈ 18 d; ≥ 9 d assumed)
60·R_BLK_MAX + 180·R_BLOB + SLASH_ABANDON + 60·ATT_REWARD_PER_BLOCK = 3,626 TAIKO ≤ B_SEAT / 2 = 10,000  (per-term exposure; 180 = 60 blocks × 3 blobs)
SLASH_ABANDON > 60·R_BLK_MAX = 1,440                      (paying a lander always dominates abandoning)
Q(m) = ⌊2m/3⌋ + 1; 2Q(m) − m                              (provable double-signers behind a locked block: 12 at m = 32, 6 at m = 16, 4 at m = 8)
K_MIN_CERT = 8 ≤ committee size, else no-committee mode   (4 provable double-signers at m = 8; below that a certificate says little)
MIN_OWNERS = 6 distinct owners, ≥ 44 seats at initEtna     (K + CAP + V_MAX: a full committee exists with the primary owner excluded)
DEGRADE_AFTER = 7,200 s < ROLE_HORIZON                    (single-proof mode arms long before the horizon)

3. What must be measured before freezing

  • A term's revenue (base-fee share, tips, MEV) on mainnet for a week: sets B_SEAT, MISS_PENALTY, SLASH_ABANDON, the reward band and the attester share (open items G8, G10).
  • Mainnet gas of the RISC0 and SP1 leaves; the EIP-2537 aggregate path for 32 keys; the registry walk; the forced-inclusion queue walk.
  • Gossip and execution latency on a 32-attester devnet: sets TIMEOUT, STALE_MAX, CERT_LAG_MAX and validates the 1-s cadence.
  • Guest cost of 64 KZG versioned hashes and of a 4,096-header L1 chain.
  • Blob-fetch latency under sparse blob pools: sets FI_DELAY.
