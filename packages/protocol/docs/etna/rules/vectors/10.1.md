# 10.1 — accept/reject vectors

**Non-normative.** [SPEC.md](../../SPEC.md) and its incorporated [UPGRADES.md](../../UPGRADES.md) define the timestamp-triggered checkpoint pause. Each case below tests the named rule; failures use its stated consequence.

## START-10.1-1

| Vector     | Setup                                                                                                                      | Expected                                                                                                          |
| ---------- | -------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 1.a accept | ordinary EL fork: publish T, old rules through eligible H, settle/activate, new rules H+1                                  | conforms                                                                                                          |
| 1.b accept | structural K change uses the same pause on common grid G=lcm(oldK,newK)                                                    | conforms                                                                                                          |
| 1.c reject | switch new execution rules immediately at timestamp T before checkpoint activation                                         | violates START-10.1-1/6; wrong-rule block invalid (CONS-3.4-8)                                                    |
| 1.d accept | wall-clock T passes while chain is stalled, or proving/finality delays activation                                          | no automatic time-only activation or downtime guarantee                                                           |
| 1.e reject | an in-place plan changes timestamp construction, the historical pause predicate, or anchor freshness/slot-282 maxAnchorAge | violates START-10.1-1; these deployment invariants require separate deployment and separately specified migration |
