# Rule index

**Non-normative index.** Statement text lives in [SPEC.md](../SPEC.md); this table maps an ID to its type, a title and its verification assets. Where this table and SPEC.md disagree, **SPEC.md governs**.

`Type` records whether a statement binds: `rule` binds; `limitation` and `assumption` do not - see [README](README.md#what-an-id-means-a-citation-handle-plus-a-type).
