# 5.1 — review notes

**Non-normative.** Nothing here can be conformed to or failed against. This is what decomposing [SPEC.md](../../SPEC.md) section 5.1 into citable statements turned up. Each item says what would close it. Only the spec owner decides.

## Normativity boundary

Every sentence in 5.1 carries an ID (DATA-5.1-1 ... DATA-5.1-3). The section is one paragraph; the three markers split it into the envelope format, the `data_hash` commitment and the propagation rule. There are no un-numbered sentences in the section body, so no boundary table is needed.

## Q5.1-1

**Is "never goes to L1" a prohibition or a description?**

**Text.** DATA-5.1-3: "It propagates only within the consensus network and never goes to L1."

**Why it matters.** Read as a rule, it forbids a node or lander from publishing the envelope (and the witnesses it carries) on L1, but names no enforcer or consequence. Read as a description, it says only that the protocol's data path does not require it; a public archive of envelopes would not violate 5.1, though it would change the privacy story and the DA's assumption that the envelope is a private proof input. Section 5.2 reinforces the privacy reading, but neither section states an obligation.

**Would close it.** Say whether publication is prohibited (and by whom, with what consequence) or is merely outside the protocol's public data path.

## Q5.1-2

**Does "each CometBFT block" include a pause placeholder with no transactions?**

**Text.** DATA-5.1-1: "The single tx in each CometBFT block". Section 8's pause path says PrepareProposal "returns a placeholder proposal with no transactions, which ProcessProposal rejects".

**Why it matters.** A placeholder proposal has no transaction, so it cannot carry the envelope; yet it is produced as a CometBFT proposal. If DATA-5.1-1 is read literally, every pause placeholder violates it. Section 3.1 says each block's `Data.Txs` holds exactly one item, which suggests the envelope rule is for decided blocks, not rejected placeholders. The text does not state that exception.

**Would close it.** State that DATA-5.1-1 applies to a decided/proposed block that is not a pause placeholder, or carve out the placeholder path explicitly.
