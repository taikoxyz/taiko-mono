## Q6.1-5

**"The ordered landing checks" versus "the remaining order is illustrative"**

**Text.** "The ordered landing checks begin with range, grid, sealed pause-height bound and origin record; the leaves are exactly those of the grid points in (p,h) and the leaf at c matches the current checkpoint record; FI head advance; reference block and blobs; computing cutHash and the statement; first-seal preconditions; verifying both proofs. All first-seal checks precede proof verification and storage writes." … "the remaining order is illustrative."

**Why it matters.** The two sentences can be read as (a) the enumerated order is binding and only the internal order within a check group is illustrative, or (b) only the explicit constraints bind — all checks before any state change, and leaf and first-seal checks before proof verification — while the enumeration is presentation. The readings differ observably: under (a), verifying proofs before the range check does not conform; under (b) it does. A vector cannot settle it, because the difference is in what a conformance test may assert.

**Would close it.** Say which ordering constraints are normative, or describe the enumeration as presentation and retain only the explicit ordering constraints.
