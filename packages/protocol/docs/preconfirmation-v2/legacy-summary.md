> 取代的既往工作中值得保留的结论。全部原始文档（v15 提案全文、现状评估、十余轮
> 评审记录、模型检查器、幻灯片、角色拆分评估中英双语版）保留在分支

## 1. 被取代的 v15 设计线，一段话

v15（"永续拍卖 + commit→publish→seal epoch"）：单一席位持有者（seat holder）通过
常驻拍卖独占每个 epoch（384 秒）的排序权，按 epoch 提交承诺（EBC）、发布数据、
提交证明封存；配套强制包含队列、可用性证书、默认派生规则、完全无政府模式
（Total Anarchy）、降级阶梯等机制，经十余轮对抗评审收敛（round 11–13 归零）。
被取代的原因：所有者判定其活性粒度不足——席位故障造成 epoch 级（分钟到小时）的
服务中断，并确认**亚 epoch 级故障切换是产品需求**，遂转向按 slot 轮换构建者的
Slot-Chain 设计。

## 2. 保留的关键事实与结论

**关于 v15 的活性（评估文档核算，多轮复核）：**

- v15 中静默（宕机）持有者是**按次终止**的（漏一次 EBC = 已结清过错证书 = 终止
  触发），配合候补晋升，服务中断 ≈ 3–4 epoch（20–26 分钟）——前提是候补簿非空。
  真正无界的情形是**候补簿为空**；最坏的有界拒服窗口属于不被罚没的怠工/填塞者
  （`K_empty` ≈ 1.7 小时 / `T_max` 数周），而非宕机者。
- 教训（进入 v2 的动机）：把"服务切换速度"与"席位终止速度"解耦；亚 epoch 切换
  只有轮换（排班表）一条路，因为唯一 L1 可读的故障信号按 epoch 出现。

**关于强制包含（forced inclusion）——不可删除，高置信度：**

- 它是审查抵抗的唯一无条件底线：轮换只在"≥1 诚实构建者"时给有界等待，对全员
  卡特尔给零保证，且链上无法检测卡特尔；没有强制载体，被审查的桥接存款本金是
  **被冻结**而非被延迟。没有任何严肃 L2 移除过它；生态方向（含 L1 的
  FOCIL/EIP-7805）是加强此类底线。v2 以逐块电路义务 + 双侧条件逃生阀的形式保留
  （spec §7），日常成本近零。
- 已部署合约本就带着这一直觉：`saveForcedInclusion` + 强制消费已上线
  （`MainnetInbox.sol` 中 `forcedInclusionFeeInGwei = 1_000_000`、休眠的
  `permissionlessInclusionMultiplier = 160` 即"逾期 ⇒ 向任何人开放提议"）。

**关于 Total Anarchy：** 其窄删除（禁用自由裁量无政府通道）在 v15 中就是参数
`W_a = 0`（v15 §13-S.19 的 Phase-A 默认姿态）；在 v2 中因"落地无需权威、任何人可
兜底"而整个机制不再需要。

**关于泛化的构建者/聚合者拆分（评估文档的核心结论，v2 的解法对照）：**

| 评估发现的坑 | v2 的对应解法 |
| --- | --- |
| 单点故障只是从构建搬到聚合（ePBS"免费期权"拓扑） | 签名链使落地无需权威：lag 超限任何人兜底，兜底落地即失职罪证（spec §6.3） |
| 构建者过错全落入依赖瞭望塔的弱执行类 | 双签 = 同 slot 两个签名块头，L1 合约直接验签罚没，无仲裁期（spec §4.3） |
| 构建者↔聚合者公平交换成为承重件 | 签名覆盖父块哈希：中间删除结构性不可能；跳过/扣体降级为签名在案、无收益的威慑级残留（spec §5.4/§5.5） |
| epoch 判定机制需整体重写 | v2 即该重写：原子落地（接受即最终）删除 EBC/判定/取消级联全套 |

**在线核实过的外部先例（核实日期 2026-08-24）：**

- ePBS 免费期权问题：[arXiv:2509.24849](https://arxiv.org/abs/2509.24849)
  （~8 秒期权窗口已具经济显著性——聚合者扣留是同一拓扑，v2 用兜底落地压制）。
- dYdX 指定提议者："全部提议者下线 ⇒ 网络停摆"，靠加速治理恢复——主权链姿态，
  L2 无社会重启路径，故 v2 不采用"无席位即暂停"。
- [EIP-7805（FOCIL）](https://eips.ethereum.org/EIPS/eip-7805)、
  [flashbots/rollup-boost](https://github.com/flashbots/rollup-boost)（生产环境
  构建/结算拆分均保留本地兜底路径）。

**从 v15 直接沿用进 v2 的机制资产：** 常驻拍卖骨架（绑定竞价、候补队列、`q` 过渡、
`T_max` 重拍）、过错方付费的无许可替补模式、锚定新鲜度/单调约束、销毁主导的罚没
分成（≥80% 销毁 + 预承诺受益人）、参数设置器的不变量检查纪律。
