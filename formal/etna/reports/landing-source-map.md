# Etna land() ordered source map (V8)

Source inspection at paired protocol `cf4095818050bd670d7d6b8b9f742d55c01e49f0` (V8). The actual-contract conformance run in `reports/landing-conformance.json` exercises every row below. V8 differs from V6 in three places: the `ZeroRewardRecipient` check, the twenty-word statement, and `_recordReward` between the verifier and the fee payment. This is a source/spec and conformance map, not Solidity bytecode refinement.

Paths in tables are relative to `packages/protocol/contracts`; `Inbox` means `layer1/etna/impl/EtnaInbox.sol`.

## Reference helper and blob environment

`Inbox:558-575`:

1. require uint64 reference<current block.number (uint256), else AnchorUnavailable. Only then age=current-reference; safe subtraction.
2. age<=256: use BLOCKHASH(reference); do not call history.
3. age>256: require age<=8191, else AnchorUnavailable. STATICCALL `0x0000F90827F1C53a10cb7A02335B175320002935` with `abi.encode(uint256(reference))` (32-byte input). Require call success **and** returndata.length==32; else AnchorUnavailable. Decode raw bytes32 only after exact length.
4. Require selected hash!=0; else AnchorUnavailable.

`Inbox:579-590`: count BLOBHASH(0),BLOBHASH(1),... until first zero; count must be nonzero else BlobsRequired. Allocate count words, reread indices0..count-1 in order. This is the current transaction's nonzero prefix, not caller-supplied hashes. Environment stability across both passes and a finite zero suffix are EVM/transaction premises; without them a general stream model could be nonterminating or change between passes. Do not hard-code a max blob count absent from this source; fork block/transaction limits and gas/alloc failure belong to the environment boundary. Success properties do not need to prove unlimited-gas availability.

`hashLandStatement` public view helper (`Inbox:304-325`) deliberately accepts supplied reference/hash-list and parent fields and does not perform land checks. It is an encoder API; do not use its successful return as proof of a legal landing.

## Boundaries and precise spec adjustments for the next worker

- **Typed inputs/dispatch:** eight-field V8 LandInput is uint64/bytes32/bytes32/uint64/uint48/address/address/uint256 (`IEtnaInbox.sol:102-124`). ABI rejects invalid widths/malformed calldata and nonpayable value before body; a typed Lean entrypoint may make this explicit as an adapter boundary rather than model decoder bytecode.
- **Environment:** authentic/stable block.number, block.chainid, BLOCKHASH, finite ordered BLOBHASH prefix, exact history response; proxy delegatecall/address semantics and STATICCALL restrictions. Source proves branch/window/nonzero/length checks, not correctness of supplied environment data.
- **External implementation:** pin concrete SignalService semantics above or parameterize its outcome and frame relation. “Normal return stores the checkpoint” is not guaranteed by the interface for an arbitrary contract at that immutable address. Verifier normal return only gives guest validity under real verifier soundness; MockLandProofVerifier/Dummy does not provide it.
- **EVM journal:** expose tentative head/checkpoint/external logs/transfers and guard state. For each late failure, apply generic transaction rollback to the trace; do not define model failure as prestate without semantic connection. Restrict restored state/effects to journaled transaction world, excluding gas fees/nonce.
- **Same-Inbox reentry:** prove from guard tload2 that well-formed nested land/save fail before their bodies. Locks are per execution account; this does not forbid calls to another Inbox, authorized non-guarded upgrade paths or arbitrary recipient actions. A verifier is static; a stateful verifier callback model would overstate this source behavior.
- **Concrete modeling mismatch to avoid:** strict Require/statement/consume/checkpoint/signal/log/verifier/payment order is source-visible, but the relative evaluation of reference and blobs as sibling arguments is not a source-established total error precedence. For LAND success prove both checks; for combined failures either use an explicit compiler-order/conformance boundary or abstract the outcome to the set of allowed failed subchecks. Do not silently claim a source-backed “reference error wins” contract.
- **Other source-visible exclusions:** do not add a paused/owner check, early local zero terminal hash/root check, zero-recipient exception for no fees, unconditional payment CALL, or “lastHash/stateRoot stored together in Inbox” (Inbox stores only height/hash; service stores root). Do not require successful callback final balance gain equals fees. These would disagree with the mapped source.

## Implemented Lean map

- `Model.validate`: source lines 254, 258-262, 267-271 in the table's exact order.
- `Model.execLandSteps`: transient guard acquisition before body checks; entry failures
  retain locked tentative state except already-locked rejection; environment failures
  precede durable writes. Source sibling reference/blob failures have an unordered class.
- `referenceHash`: both reference branches, history success/exact length and final nonzero.
  `actualBlobs`: finite stable transaction prefix; `AuthenticEnvironment` relates returned
  contents to a canonical block-hash function and concrete transaction blob list.
- `makeStatement`/`computedStatement`: all 20 source values, exact ASCII32 tag, proxy context,
  ordered-prefix hash primitive; actual execution retains the computed statement.
  `Statement.decode_encode`, `natWord_injective`, `every_word_independent` recover all fields
  unconditionally. `hash_binding` separately needs local separation of the actual pair.
- `execChecked`: conditional queue write; checkpoint write; concrete SignalService checks,
  service checkpoint+log; batch log; void verifier normal/revert outcome; conditional nonzero
  reward record (`execReward`, `recordReward`: occupied-slot revert, commitment write and
  event); payment; consumption log only on moved head; unlock. `checked_success` composes
  the named steps. Actual external return facts concern
  the specific invoked call, never a Boolean return value from verifyProof.
- `Journal.write` retains parent frame; `rollback` recursively unwinds nested business
  snapshots. `execution_journal_root` proves every path remains rooted in the initial World.
  `EvmJournalLaw` quantifies over arbitrary journals/interpreters, independent of Landing;
  `rollback_atomic_evm` derives restored state rather than assuming the target equality.
- `recipient_bound`, `consumption_event_exact`: transfer-instruction target/amount and event
  data; `fee_interval_add` and `successive_no_double_consumption`: interval composition.

Model projection / external boundaries: World contains Inbox identity/configuration and
checkpoint, retained fee map/head/tail, SignalService checkpoints, Inbox-issued transfers,
protocol logs, Inbox balance and same-account guard. Recipient private storage, unrelated
callback logs/transfers, sender nonce and gas charging are outside this projection. The
callback frame forbids an authorized malicious upgrade or non-guarded configuration change
while land runs, and prevents direct external storage writes into Inbox. Same-account
land/save attempts are rejected by the modeled guard, not postulated successful-call facts.
Different Inbox accounts are not locked globally. Verifier callbacks are static and cannot
change state. Authentic environment data, actual cryptographic primitives, ABI dispatch,
proxy context and EVM journal/frame semantics remain explicit assumptions when applying
these source-level specification proofs to EVM executions. There is no bytecode refinement.

The required test harness actually observes proxy SHA3 input, STATICCALL kind, state writes,
raw executed logs and value-call target/amount. Committed logs are inferred from successful
call completion plus the named EVM journal law, not independently read from receipts.

### Review fix: inner byte-hash linkage and composition

`computedStatement` now calls `keccakBlobBytes(serializeBlobPrefix(actualBlobs(e)))`.
The canonical packed preimage is concatenated big-endian32-byte typed words with no
length/offset prefix. `serializeBlobPrefix_injective` recovers lists of arbitrary
lengths by32-byte take/drop and bounded numeric injectivity. `LocalInnerHashSeparation`
is tied to precisely this byte primitive and these serialized actual prefixes.
`composed_statement_blob_binding` first derives18-word equality under local outer
separation, then recovers inner digests via numeric-word injectivity, and finally
recovers complete ordered prefixes under local inner separation. Its premises never
supply the desired blob equality. Finite unequal-length and successful matching-pair
witnesses, plus explicit exclusion of constant-inner-hash separation, are audited.
