## What the source requires

Keep the parent’s anchor while fresh, canonical, within the origin and U bounds. Carries authenticate the whole Inbox tuple. On a change the node compares the checkpoint EL hash on its own ancestor at a height at most the parent. The guest verifies witness storage. The node’s independent latest-finalized view can close signing even on a branch with a valid inherited anchor. A known new finalized checkpoint makes signing pending. For a post-origin target the node must compare EL and Comet; at the current generation origin the local hash comparison is EL only, with separately authenticated origin and genesis. A mismatched EL closes the gate immediately even if the record is unavailable. A new finalized generation revokes old-domain signing. ## Outcome and bounds

Main positive history has a real FI prefix and suffix. P10→12 lands at L1 600. H13 inherits B with gap 3. H14/B fails with gap 4 even though actual c is 12. H14/C succeeds. Both overlapping jobs are prepared using reference 700 before either lands. Short then long installs c13 with head1 and c14 with head2. The unchanged long settles H14 alone with the original statement intact. In the reverse order the long also succeeds, directly from c12, leaves c13 unrecorded and makes the short stale. In each ordering the saved parent follows the transaction that actually landed. Learning each new checkpoint affects the node’s signing gate independently of its old block anchor.

The source already states the full cut comparison in LAND-6.1-8 and normative reference lines 332–343. No extra source contract is needed. In a finite model containing a single coherent history with sound immutable proof construction, c’s only possible cut already matches. Removing the equality alone can then be observationally redundant. The source acknowledges separately certified divergent histories beyond its ordinary quorum non-equivocation assumptions (§6.3 and RECOV-8.1-7). A fabricated mismatch is an interface control. It establishes expected rejection, and carries no evidence of a reachable normal-history fault, a guest failure, or a defect in the draft. A control for the FI-cursor field need not posit two histories with same full EL/Comet identity and different independently derived FI cursors.

The valid H15 exit can be discarded under an additional outage premise. Effective support is K=131072, the source’s reference value (Q6.3-1 leaves universal status and enforcement open). H15’s ordinary anchor C is at 600. At N=140000 the widest past-reference window permits only r in [131809,139999]. Even the minimum r−600=131209 exceeds K with either endpoint-count convention. Previously signed readable candidates are too recent to reach C, and any sufficiently old reference is unreadable. Every proof containing H15, even one originating at H14, normally authenticates C for H15. BATCH-6.3-4 through -7, LAND reference lines 351–358 and PROOF-6.2-33 apply. The independent interruption prevented settlements until this point. H14 was independently audited with preserved evidence. Fresh governance therefore has last provable c=14 on the specified history. Before that loss of provability the recovery contract could execute a valid authorization but DAO operating rules require landers to settle through the last provable height first. The c12 authorization capture tests only contract stale-input semantics. If H15 settles in time its exit survives. The governance path depends on available archives, audited landings, healthy and nonconcentrated controllers, diagnostics, time for the selected authorization path and all on-chain checks.

The post-recovery positive proof option uses ordinary roots at or after R=141000 and reference141200. The previous landing record at14 remains a valid proof origin. Because the old-domain EL parent anchor is never inherited by the new first block, neither C nor the pre-R outage is in that new ordinary ancestry chain. Symbolic hash and blob names assume valid independent proof construction, consensus certificates, EL execution and FI processing. The finite fixture does not establish actual guests, K-enforcement or cryptographic behavior.

## Small finite search

Use four fixed seated units, one indexed exit, two generations, heights 10..17, U=3, at most the eight named canonical L1 states, two overlapping jobs plus the initial job, a bounded FI cursor 0..2, one pending checkpoint comparison, one outage jump, one recovery, one rotation. Encode reference and ancestry distance as checked deterministic arithmetic on the sparse L1 numbers. Admit both job orders, permitted anchor adoption or inheritance, target arrival and pinned compare, stale versus fresh recovery, and the post-R set selection. An accepted fresh transition needs an independently supplied authority/audit premise and last-provable condition. Use out-of-band one-field identity controls for cut mismatch, separating them from the ordinary history. No completeness result follows for broader histories, general chain divergence, equivocation, archive availability, liveness or the previous committee Free objective.

The JSON lists five categories of semantic controls and its positive neighbors: lagged U, exact cut identity, immutable range, origin-only authority, and rollback/first-two reset. The independent latest-finalized signing gate needs a separate state check; each target must be held pending on an incomplete comparison and opens only after a full required match. Producing the right committee labels at final height alone cannot show the gate ever closed.
