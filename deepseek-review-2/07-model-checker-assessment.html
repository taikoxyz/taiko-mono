7.2 Model inventory (what IS checked)

State: per-epoch status (SEQ/UNRESOLVED/CONTENT/EMPTY/VOID/SEALED/CANCELLED), owners, ordered forced queue with terminal consumed/refunded sets, per-epoch tolled open-age, commit one-shots, certificate/consumed/withdrawn sets, lineage tags, proving-outage flag. Actions: tick (with deterministic auto-resolution of the decision window), outage start/end, decide, ac_certify/ac_timeout, miss_commit, anarchy_propose, equivocate, seal_content/seal_empty, close_void, cancel, debit, promote, safety_settle_late, withdraw. 12 state + 12 edge invariants; backward-BFS liveness in two relations. This is a faithful abstraction of the epoch state machine, including the v14 AC-resolution branch, the challenge-horizon withdrawal gate, and the no-false-successor-slash tolling property.

7.4 Documented deviations and their fairness

  • Effectively-open tolling (not the doc's "universal descendant tolling"): a descendant's seal deadline runs behind a prefix of proof-free-closeable EMPTY/VOID epochs. Documented, with a measured justification (strict tolling produced 13,336 spurious outage-robust halts of the delayed-free-close class) and a compensating invariant (inv_no_seal_fault_behind_blocking). This is a defensible scoping decision, honestly recorded.
  • Decision as a window [e, e+1] instead of the single atomic D+κ instant: conservative over-approximation, documented.
  • RESERVE0 validates the checker's own 3·NEPOCHS+1 formula, not the doc's tranche/Λ×MEV sizing — the solvency invariant is checked, the doc's sizing is not.

RESULTS.md 563–571: "whose relation already contains every v10, v11 and v14 mechanism" — false as stated: the relation omits blob-expiry cancellation, K_empty, T_max, the auction, H_toll_max, and attested-outage tolling.   2. The precise true claim is deadlock-freedom.
  3. README simulation blurb is stale for v14 (omits the round-12 AC/horizon/tolling additions and the 24-mutant count) — cosmetic but contradicts the README's own accuracy standard.

7.6 Bottom line on the verification artifact

As evidence that the logical epoch state machine is safe and deadlock-free — including the two-sided anarchy cutoff, the one-shot commit + L1-direct equivocation, the AC resolution branch, ordered forced re-queue with refunds, and the challenge-horizon withdrawal gate — the checker is convincing and reproducible. As evidence about the protocol, it must be read with the gap table above; the auction, tenure economics, timestamps, anchors, and the newest v14 rule are outside its relation, and the exhaustive depth (2 epochs) is a stated limitation (NEPOCHS = 3 exceeded the 14M-state cap on this machine; multi-descendant cascades remain unchecked). This review's independent simulations (auction_sim.py) cover the auction/economic gaps the checker cannot.
